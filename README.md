tMod 解包工具 v1.0.0
====================

作者:朱鸿
邮箱:1594528711@qq.com

一款用于解包 tModLoader .tmod 模组文件的 Windows 桌面工具。
支持批量解包、保持原始目录结构、SHA1 完整性校验,并可将 .rawimg 贴图自动转为 PNG。

------------------------------------------------------------------------
系统要求
------------------------------------------------------------------------
- Windows 10 (1607+) / Windows 11,64 位
- 无需安装任何运行环境(程序已内嵌所有依赖)

------------------------------------------------------------------------
功能特性
------------------------------------------------------------------------
1. 批量解包:支持一次拖入多个 .tmod 文件,或添加整个文件夹(自动递归查找)。
2. 原样提取:保持模组内部原始目录结构,文件名与路径不变。
3. 版本兼容:同时支持新版(tModLoader 0.11 及以上,含 2025 日期版本)与旧版格式。
4. 完整性校验:内置 SHA1 哈希校验,确认文件未被篡改或损坏。
5. 贴图转换:可选将 tModLoader 私有的 .rawimg 贴图同步转为标准 PNG,便于查看。
6. 实时日志:带时间戳与级别的彩色日志面板,完整记录解包过程。
7. 安全提取:防止路径穿越攻击,输出目录可放心选择。

------------------------------------------------------------------------
使用步骤
------------------------------------------------------------------------
1. 启动程序。
2. 将 .tmod 文件拖到列表区,或点击「添加文件」/「添加文件夹」按钮。
3. 在「输出目录」选择解包结果保存位置(默认桌面 tmod_unpacked 文件夹)。
4. 按需勾选选项:
   - SHA1 完整性校验:校验失败会在日志中警告(不阻止解包)。
   - 同时把 .rawimg 转为 .PNG:提取时额外生成同名 PNG。
   - 完成后打开输出目录:解包结束自动打开资源管理器。
5. 点击「开始解包」。进度条与日志实时显示进度。
6. 解包结果保存在:输出目录\<模组内部名>\ 下。

操作提示:
- 在文件列表上右键,可「移除选中」或「重置状态」。
- 解包过程中可点击「取消」中止(当前文件处理完后停止)。
- 日志面板可点击「隐藏」折叠;「清空日志」清除历史。

------------------------------------------------------------------------
常见问题与错误处理
------------------------------------------------------------------------
Q: 提示「无效的文件头」?
A: 文件不是有效的 .tmod,或扩展名被误改。请确认是 tModLoader 模组文件。

Q: SHA1 校验失败警告?
A: 文件可能被第三方修改或下载不完整。建议重新下载官方版本。工具仍会尝试解包,
   但解出的内容可能与官方原版不一致。

Q: 某文件「DEFLATE 解压失败」?
A: 该文件数据损坏。检查 .tmod 是否完整;若是旧版模组,可能存在格式差异。

Q: rawimg->PNG 转换失败?
A: 部分非常规尺寸或新版本 rawimg 可能无法转换,原 .rawimg 文件仍会正常保留。

Q: 解包出来的 .dll 是什么?
A: 模组的编译后程序集(.NET)。如需查看源代码,请使用 ILSpy/dnSpy 等 .NET 反编译器。

Q: 程序闪退或无响应?
A: 请检查文件列表中的 .tmod 是否过大或损坏。日志面板会记录详细错误堆栈,
   可截图反馈。

Q: 卸载后残留文件?
A: 安装程序会在卸载时清理程序目录。输出目录(桌面 tmod_unpacked)需手动删除。

------------------------------------------------------------------------
关于 .tmod 格式
------------------------------------------------------------------------
.tmod 是 tModLoader 的模组打包格式,结构为:
  TMOD 头(4字节) + tModLoader版本(字符串) + SHA1哈希(20字节)
  + 签名(256字节) + 数据长度 + 模组名/版本 + 文件表 + 文件数据。
文件表中每项记录文件名、未压缩长度、压缩长度;数据段中每个文件独立存储,
若压缩则为 raw DEFLATE(RFC 1951)压缩;png/mp3/ogg 等不压缩。
本工具参考 tModLoader 官方源码实现解析,保证兼容性。
